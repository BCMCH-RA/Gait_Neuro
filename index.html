Requires a Web-Bluetooth-capable browser (Chrome/Edge on desktop or Android) served over HTTPS or from localhost.
Flash the paired C3_IMU.ino sketch onto all 3 boards (Seeed XIAO ESP32-C3 + MPU6050), changing only DEVICE_ROLE per board.
Firmware timestamps use each node's own millis() clock, corrected to host epoch time at Start via a BLE time-sync handshake.
Raw IMU counts are converted to physical units in the CSV using ±2 g / ±250 dps full-scale (must match the firmware's ACCEL_RANGE_G / GYRO_RANGE_DPS).
